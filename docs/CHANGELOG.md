# Changelog

Memode の更新履歴。形式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) ベース、バージョニングは [SemVer](https://semver.org/lang/ja/)。

`scripts/release.sh` が `[Unreleased]` を `[X.Y.Z] - YYYY-MM-DD` に切り出し、そのセクションを GitHub Release のノートと Sparkle の更新ダイアログ（appcast の `<description>`）の両方に流し込む。ここが唯一の源。

## 書き方

リリース時に Claude Code のセッションが `git log <前回タグ>..HEAD` を読んで `[Unreleased]` を埋め、commit してから `mise run release` を叩く。コミットごとには書かない。ここを読んだだけで書ける粒度で書いてある。

### 1. フォーマット

```markdown
## [Unreleased]

### ✨ Added
- メニューに「アップデートを確認…」を追加

### 🐛 Fixed
- レイアウト画面がドラッグ後の配置に追いつかないことがあるのを修正
```

- 1 項目 = 1 行。継続行は書かない（HTML 変換が `- ` 始まりの単一行しか拾わない）
- インライン Markdown は `` `code` ``・`**strong**`・`[label](url)` のみ
- 体言止め（「〜を追加」「〜を修正」「〜に変更」）。主語は書かない

### 2. カテゴリ

```
✨ Added       — 新しい機能・メニュー項目・設定
📝 Changed     — 既存機能の挙動・既定値・配置の変更
🐛 Fixed       — 期待通りに動かなかったものが直った
🗑️ Removed     — 機能・設定の削除
```

使わないカテゴリの見出しは書かない。

### 3. 書くもの・書かないもの

- **書く**: ユーザーが目で見て・触って気づく変更だけ
- **書かない**: 内部リファクタ・テスト・ドキュメント・ビルド/リリーススクリプト・CI・依存の更新
- dev 版（Memode-dev）にしか影響しない変更も書かない
- 該当するものが無いリリース（配布基盤だけの修正など）は「- 内部的な変更のみ」と 1 行書く

## [Unreleased]

## [1.0.1] - 2026-10-02

### 📝 Changed
- ウィンドウの幅を超えた行を折り返して表示するように変更

## [1.0.0] - 2026-10-01

### ✨ Added
- 入力中に ⌃L で mycast を開き、クリップボード履歴から選んだものを memode に貼れるようにした

### 📝 Changed
- Tab で常に半角スペース 2 つを入れるように変更（ファイルから字下げ幅を推測しない）
- 最後のタブを閉じたら空の scratch を出すように変更。空の scratch を閉じたときだけウィンドウを隠す

### 🐛 Fixed
- 日本語の変換中の文字が二重に描かれて滲むのを修正

## [0.1.5] - 2026-10-01

### ✨ Added
- タブをドラッグして並べ替え・左右の分割のあいだで移動できるようにした（分割していないときはエディタの右半分に落とすと分割する）
- Cmd+Opt+←→ で隣のタブに切り替えられるようにした

### 📝 Changed
- ステータスバーの「ウィンドウの位置とサイズを元に戻す」ボタンのアイコンを、リロードに見えない形に変更

## [0.1.4] - 2026-10-01

### 📝 Changed
- 見た目を一新し、後ろが透けるガラスの枠に、文字を書く面だけ濃い板を浮かせるデザインに変更
- タブを角の丸いボタン型に変更し、ファイルの種類ごとの色の点を追加。未保存の印は × の位置の点に変更
- Cmd+P と言語の選択の一覧を大きく見やすく変更
- Markdown の見出し・リストの記号・チェックボックス・済みの行（取り消し線）・インラインコードを色分けし、コードの色もガラスの見た目に合わせて変更
- ウィンドウを出すときにふわっとフェードインするように変更
- 空のメモのタブ見出しを「無題-N」から「scratch」に変更

## [0.1.3] - 2026-10-01

### ✨ Added
- タブバーのタブの右の空きを掴んでウィンドウを動かせるようにした（位置と大きさは画面ごとに覚える）
- メニューバーのメニュー・メインメニュー・ステータスバーのボタンに「ウィンドウの位置とサイズを元に戻す」を追加
- JSON・TOML・`.gitignore`・diff・`.zshrc`・`.env`・`.plist`・`.vue`・`.svelte` などにシンタックスハイライトが付くようにした
- 拡張子の無いスクリプト（`bin/rails` 等）は 1 行目の `#!` から言語を決めるようにした

### 📝 Changed
- 最後のタブを閉じたらウィンドウごと隠すように変更
- Cmd+P の候補から開けないファイル（画像・PDF 等、10MB を超えるもの）を外した

## [0.1.2] - 2026-10-01

### ✨ Added
- メニューバーのメニューに「データのフォルダを開く」を追加
- ログイン時に自動で起動（初回の起動で ON。メニューバーのメニューの「ログイン時に起動」で切り替え）
- ステータスバーの右端に今の版を表示（押すとアップデートを確認。新しい版があると「vX.Y.Z に更新」に変わる）
- Finder のダブルクリックや「このアプリケーションで開く」でテキストのファイル（`.md` `.txt` `.json` 等）を開けるようにした（既定のアプリにできる）

### 📝 Changed
- セッションと最近使ったファイルの置き場所を `~/Memode Data` から `~/Library/Application Support/Memode` に変更（起動時に自動で移す）

## [0.1.1] - 2026-10-01

### 📝 Changed
- セッションと最近使ったファイルの置き場所を `~/Memode` から `~/Memode Data` に変更

## [0.1.0] - 2026-10-01

### ✨ Added
- 左 Shift のダブルタップで出し入れするポップアップのエディタ（隠しても続きから書ける）
- タブと左右分割、主要な言語のシンタックスハイライト
- VS Code と同じキー操作（Cmd+Opt+↑↓ で複数カーソル、Opt+↑↓ で行の移動など）
- メモの自動保存と、再起動後の復元
- Cmd+O・Cmd+P（ホームの下のファイルをあいまい検索）・`memode` コマンドでファイルを開く
- ファイルの保存（BOM と改行コードは読んだときのまま）と、外で書き換わったときの確認
